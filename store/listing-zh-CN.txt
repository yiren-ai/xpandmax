名称：XpandMax

简短描述：在 X 作者名下显示蓝色粉丝数与简短中文简介，点击展开完整资料。

详细介绍：
XpandMax
帮你在 X 上连接更大的世界。

XpandMax 在作者名下直接显示蓝色粉丝数和简短中文简介，帮助你快速了解账号背景。整行统一 12px 常规字重，不挤占帖子正文。

支持的场景：
• 信息流、帖子详情与回复中的作者。
• 引用帖中的原作者。
• 搜索结果、关注者列表、关注列表与推荐账号。

未关注的帖子作者旁显示「关注」，用户点击后直接激活 X 原生关注，成功后显示「已关注」，无需悬停头像。不会自动关注或批量关注。

时间线的书签按钮旁显示 X 已返回的书签数量。打开帖子原生分享菜单可以选择「复制为 Markdown」，复制接口返回的正文、展开链接、媒体和作者来源；两项功能均可在插件弹窗关闭。

帖子、回复和引用帖默认显示一行简介，点击可展开完整简介、所在地和原文切换，同时最多展开一位作者。再点或按 Esc 收起。账号列表仍可悬停粉丝数查看资料。所在地是账号填写的信息。

支持的桌面 Chrome 可在本机将外文简介自动翻译成中文，首次使用按提示启用浏览器语言包，可随时查看原文；不支持时保留原文，也可主动选择免 Key Google 在线翻译，或配置 Chat Completions、Anthropic Messages、Gemini generateContent 接口。Google 使用非官方服务保障的入口，可能限流或失效，不保证长期免费；自定义服务商可能收费。

插件仅使用 X 页面已经收到的账号数据，在当前浏览器标签页中处理。无需额外注册或 API Key，没有额外账号查询，没有统计上报，不向开发者发送数据；仅主动启用 Google 在线翻译或自定义 API 时向所选服务商发送简介。

安装后刷新 X 页面，按原来的方式浏览即可。“粉丝 —”表示页面尚未返回该账号的粉丝数，不表示粉丝数为零。数字以页面返回时为准。

默认隐藏左侧通知图标上的未读数字，可在工具栏的 XpandMax 设置中随时恢复，切换后立即生效。不会将通知标记为已读。

原“X 粉丝数”已更名为 XpandMax。storage 权限用于本机保存显示开关和翻译配置（含接口地址、模型和 Key），不云端同步。

官网：https://xpandmax.com

这是一个独立开发的工具，与 X 官方没有隶属关系。X 的页面结构或接口字段发生变化时，部分页面可能需要等待插件适配。

分类建议：社交与通信；如后台分类不同，选择最接近的社交工具分类。
默认语言：简体中文
费用：插件免费；Google 免 Key 入口不保证长期免费或可用，用户自选 API 可能收费
单一用途：增强 X 浏览体验：展示页面已返回的作者资料和帖子指标，提供原生关注入口、书签数与 Markdown 复制，并支持隐藏通知未读数字、左侧导航和右侧栏以减少阅读干扰。
站点权限理由：仅在 https://x.com/* 和 https://twitter.com/* 读取页面账号标题及已有 GraphQL 响应中的用户名、粉丝数、简介、账号填写的所在地和关注按钮所需状态，将资料匹配到作者。仅在用户真实点击关注后激活 X 原生关注动作，观察该动作的同源响应以确认结果。无额外后台账号查询，不读取请求授权头、Cookie 或密码，不向开发者发送账号数据；可选 API 翻译只向用户选定的服务商发送简介。资料只在当前标签页内存短期缓存。
storage 权限理由：使用 chrome.storage.local 保存翻译配置（含 Key）以及页面显示开关，包括是否隐藏通知未读数字、左侧导航和右侧栏，以及是否显示书签数和 Markdown 复制入口。设置只保存在本机，不同步至云端；不持久化用户名、粉丝数、简介、所在地、帖子正文、互动指标、关注状态或通知内容。
可选站点权限理由：为 Google 在线翻译及用户自选的 Chat Completions、Anthropic Messages、Gemini generateContent 接口声明可选 HTTPS 范围；保存时仅申请 https://translate.googleapis.com/* 或用户填写的接口站点权限，用于扩展后台发送翻译请求，不向其他站点注入脚本。
远程代码：不使用。所有执行代码都包含在上传的插件包内；X 返回的 JSON 只作为数据解析。

审核测试说明：
使用审核人员自己的 X 账号登录 x.com，安装插件后刷新。首页、回复、引用帖的作者名下应出现蓝色粉丝数与单行简介；点击展开完整资料，打开另一个作者时前一个收起。确认未关注的主帖作者有关注按钮，引用帖、已关注账号和自己不显示。只在审核人员实际点击后执行关注。时间线书签按钮旁应显示书签数；打开帖子分享菜单，选择「复制为 Markdown」后剪贴板应包含正文和来源链接。在插件工具栏弹窗关闭这两项后，数字或菜单项应立即消失，重新开启后恢复。原文切换及账号列表粉丝数也应正常。在插件工具栏弹窗中切换「隐藏通知未读数字」，通知角标应立即隐藏或恢复；分别切换「隐藏左侧导航」和「隐藏右侧栏」，对应页面区域应立即隐藏或恢复，重新打开页面后保持设置。无需独立账号或 API Key。

隐私申报核对：
账号用户名、粉丝数、简介、自填所在地和关注按钮所需状态仅在标签页内存中处理，不传给开发者，不持久化；可选在线翻译会向所选服务商发送简介，服务商按其隐私政策处理。应按商店后台对各数据类别的实际定义准确勾选；不要仅因为“不上传”就把读取网站数据描述为“完全不处理数据”。不出售数据，不用于广告、信用评估或借贷。
